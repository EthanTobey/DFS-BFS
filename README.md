# BFS & DFS and Word Ladder Demonstration

## Overview

This repository contains an implementation of  **Breadth and Depth First Search** in Java, along with standard operations and traversal algorithms. Both **Breadth-First Search (BFS)** and **Depth-First Search (DFS)** algorithms are included to iterate through the graph. These algorithms are further used in a demonstration that allows users to create a **word ladder** by connecting two words with only one letter difference between adjacent words, using either BFS or DFS.

### What is a Word Ladder?
A word ladder is a sequence of words where each consecutive word differs from the previous one by exactly one letter. The goal is to transform a starting word into an ending word through a series of such transformations.

## Key Features

- **Graph Implementation**: A complete implementation of a graph data structure in Java, supporting standard graph operations.
- **Breadth-First Search (BFS)**: Traverses the graph layer by layer, exploring all neighbors before moving to the next level.
- **Depth-First Search (DFS)**: Explores as far down one branch of the graph as possible before backtracking.
- **Word Ladder Demonstration**: Allows users to input two words and see the word ladder connecting them, created using BFS or DFS.

## Technologies Used

- **Java**: The project is fully written in Java, leveraging object-oriented design and graph algorithms for traversal and demonstration.
